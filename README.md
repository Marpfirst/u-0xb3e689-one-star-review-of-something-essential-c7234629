A tiny Node 22 program that writes one deadpan one-star review of an
everyday essential to `/output/entry.txt`.

Entry for the [make.fun bounty](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

## Run

```sh
node main.ts
```

It writes a single line (87 characters) to `/output/entry.txt`.
